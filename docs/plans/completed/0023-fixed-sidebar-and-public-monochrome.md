# Fixed sidebar and public monochrome

Status: completed
Owner: Codex
Last updated: 2026-08-08

## Outcome

桌面工作台使用略宽且不可拖拽改变的侧栏；空间切换与账户菜单不超过侧栏内容宽度。
未登录首页和账号弹窗统一为与工作台一致的黑、灰、白视觉。

## Scope

- 桌面侧栏展开宽度固定为 244px，继续支持收起与展开。
- 移除侧栏宽度拖拽、键盘调整和宽度持久化；中间及右侧面板拖拽保持不变。
- 空间切换菜单与账户菜单使用侧栏内容宽度。
- 首页与登录/注册弹窗统一颜色、字体、边框、圆角、阴影和交互状态。
- 保持现有注册、登录、导航和移动端行为。

## Milestones

- [x] M1 - 固定侧栏并收紧两个弹层。
- [x] M2 - 完成首页与账号弹窗单色化。
- [x] M3 - 更新测试并完成桌面、移动端浏览器验证。
- [x] M4 - 运行 `make check` 和变更范围复核。

## Acceptance criteria

- [x] 桌面侧栏不可拖拽改变宽度，展开时固定为 244px。
- [x] 两个侧栏弹层宽度不大于侧栏内容区。
- [x] 首页与账号弹窗没有蓝色或绿色主视觉。
- [x] 登录、注册、收起侧栏和移动端抽屉继续可用。
- [x] 桌面与移动端无横向溢出、裁切或遮挡。

## Verification

- 浏览器桌面端：侧栏 244px，空间菜单 216px，账户菜单 220px；无侧栏宽度分隔条。
- 浏览器移动端：390x844 首页和账号弹窗无横向溢出，弹窗完整可关闭。
- 视觉扫描：首页和账号弹窗硬编码颜色全部为中性灰阶。
- 自动化：`make check` 通过，Web 67 个测试、API 169 个测试和生产构建全部成功。
- GitNexus：变更范围为中等，未发现新增高风险执行链。

## Rollout and recovery

纯前端改动，无 API 与数据库迁移。回滚对应 Web 改动即可恢复。
