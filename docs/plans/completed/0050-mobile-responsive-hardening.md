# Mobile responsive hardening

Status: completed
Owner: Codex
Last updated: 2026-08-31

## Outcome

完善 Memora 工作台在 320–430px 手机视口下的布局、滚动、安全区和触控体验，重点修复团队记忆
内容被移动顶栏裁切、搜索浮层越出视口的问题，并在验证后提交和推送当前分支。

## Context and boundaries

- 继续保持桌面布局与现有黑灰视觉，不改变记忆权限、API 或数据模型。
- 移动端使用动态视口与 `safe-area-inset-*`，兼容刘海屏、底部手势区和浏览器地址栏变化。
- 团队搜索继续复用现有授权搜索表单，仅把窄屏表现改为视口内的底部浮层。
- 当前目标组件 GitNexus 影响均为 LOW；修改以响应式 CSS 为主。
