# Monochrome shell and account menu

Status: completed
Owner: Codex
Last updated: 2026-08-08

## Outcome

Memora 工作台统一为纯黑、炭灰、雾白的低饱和界面，并把侧栏底部账号区升级为可展开的账户菜单。
用户可以从菜单进入个人资料、邀请、订阅与账单、通用设置，或退出登录。

## Context and evidence

- 用户提供的参考图强调纯黑主画布、深灰侧栏、白灰文字、细边框和克制的高亮。
- 当前设计令牌仍以蓝色作为主要强调色，功能页还有少量硬编码蓝色。
- 现有个人资料、密码修改和套餐升级已经可用；缺少统一的账户菜单、邀请空状态和通用偏好。

## Scope

### In scope

- 将工作台设计令牌和主要交互状态调整为黑、灰、白；危险操作保留红色语义。
- 优化首页标题、输入框、侧栏、按钮、弹窗的字体层级、边框、阴影和悬停反馈。
- 侧栏底部增加账户卡和向上弹出的菜单。
- 菜单包含个人资料、我的邀请、订阅与账单、通用设置和退出登录。
- 个人资料与密码沿用现有 API；订阅入口复用现有套餐弹窗。
- 通用设置提供可持久化的紧凑布局和减少动态效果偏好。

### Non-goals

- 不修改后端身份、邀请、套餐或权限模型。
- 不引入新的字体包、主题切换后台或真实支付。
- 不复制第三方品牌、Logo 或受保护素材。

## Design and boundaries

- 全局颜色由 `tokens.css` 控制，功能组件只保留必要的语义危险色。
- 账户菜单是侧栏内的键盘可访问 popover；点击外部或按 Escape 关闭。
- “我的邀请”第一版展示当前产品的加入方式和空状态，不伪造邀请数据。
- 通用偏好保存在浏览器本地，并通过根节点 class 生效，不改变账号数据。

## Acceptance criteria

- [x] 主工作台不再以蓝色为主要界面色，背景和大部分控件为黑灰白。
- [x] 底部账户卡显示默认头像、昵称、套餐和升级入口。
- [x] 点击账户卡弹出完整菜单，所有菜单项都有可见结果。
- [x] 个人资料和密码修改继续工作，套餐弹窗可从菜单进入。
- [x] 通用偏好在刷新后保持，减少动态效果能实际关闭非必要动画。
- [x] 桌面和移动端没有遮挡、横向溢出或不可关闭的弹层。

## Verification

- 自动化：Web 组件测试、类型检查、lint、生产构建和 `make check`。
- 浏览器：1440x900、390x844，检查工作台、账户菜单、设置弹窗和套餐入口。
- 安全：不改权限接口，不记录密码、密钥或个人正文。

## Rollout and recovery

纯前端兼容改动，无数据库迁移。回滚相关 Web 提交即可恢复原视觉和账户入口。
