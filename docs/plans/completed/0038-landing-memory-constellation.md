# Landing Memory Constellation

Status: completed
Owner: Claude Code
Last updated: 2026-08-13

## Outcome

落地页 hero 获得"记忆星座"动态背景：微光尘点缓慢漂移，靠近时以发丝线相连，每 4–8 秒
一条连线以蓝色脉冲"提交"并短暂留存——把产品的记忆图谱隐喻做成环境纹理。目标质感
对标 Linear/Stripe 级克制：慢到"感觉得到而看不出来"的漂移、单事件编排、边缘遮罩，
不与标题竞争。

## Context and evidence

- 用户要求"世界级、无 AI 感"的动态背景并指定星座方向；实现前检索了业界 canvas
  粒子/星座实现要点（面积自适应密度、距离-透明度连线、空间网格、rAF）。
- 纯零依赖 canvas 实现（约 340 行组件），符合仓库最小依赖哲学。

## Scope

### In scope

- `features/workbench/landing-constellation.tsx`：DPR 感知画布；抖动网格播种（无随机
  聚簇）；三层深度（远小暗慢/近大亮快）；环绕式漂移 ~1–2px/s；空间网格 O(n) 连线、
  每点度数上限 3；蓝色"提交"脉冲状态机（蓄能 260ms → 沿线走光 560ms → 落定 900ms，
  同屏最多一个，留存提交线最多 6 条、漂离即消散）；预渲染辉光贴图。
- 可达性与性能：`prefers-reduced-motion` 或 `memora-reduce-motion` 下渲染单帧静态
  设计稿（预置 4 条提交线）；标签页隐藏或滚出视口即暂停；主题切换（含运行时）经
  MutationObserver 重读 token 调色。
- CSS：hero `isolation: isolate` + 画布 `z-index: -1`（不触碰兄弟元素定位——首版
  `> :not()` 覆写曾把绝对定位的产品舞台拉回流内挤压标题列，已修正）；径向遮罩使
  纹理避开标题列并在边缘消散。
- 测试：2 个组件测试（装饰性/aria-hidden；无 2d 上下文环境下惰性降级），TDD 先红后绿。

### Non-goals

- 无鼠标斥力等交互花活；不引入 three.js/粒子库；不在其他页面复用。
