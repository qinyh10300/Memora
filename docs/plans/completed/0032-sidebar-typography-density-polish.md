# Sidebar typography and density polish

Status: completed
Owner: Codex
Last updated: 2026-08-11

## Outcome

在不改变侧栏结构与点击行为的前提下，提高主功能和历史对话文字的字号、字重与亮度，
同时压缩垂直间距，让信息更清晰、更紧凑。

## Scope

- 调整展开状态主导航的文字、图标亮度、行高和内边距。
- 调整历史对话标题、分组和条目的字号、字重、亮度与垂直间距。
- 不改变侧栏宽度、五项导航映射、历史操作菜单或移动端结构。

## Acceptance criteria

- [x] 主导航和历史标题比当前更大、更亮、更粗，但无截断或拥挤。
- [x] 导航与历史条目的上下节奏更紧凑，点击区域仍清晰可用。
- [x] 展开、收起、hover、active 和窄屏状态无视觉回归。
- [x] 自动化检查、本地浏览器验证、构建和健康检查通过。

## Completion summary

- 根据视觉复核继续放大红框内文字：主导航与历史对话均调整为 14.08px。
- 视觉复核后将垂直节奏回调约 15%：主导航单行高度 35px，历史对话整行高度 32px。
- 历史分组标签“已置顶”和“最近”由 9.92px 提升至 12px，并同步提亮、加粗。
- 已重新构建并部署 Web 容器，浏览器完成展开侧栏视觉与计算样式验证。
- `make check` 全量通过：Web 86 项、API 184 项，包含格式、lint、类型、检索权限、OpenAPI 与生产构建检查。
