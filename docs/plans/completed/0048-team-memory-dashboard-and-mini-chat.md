# Team memory dashboard and mini chat

Status: completed
Owner: Codex
Last updated: 2026-08-30

## Outcome

参考用户提供的界面风格重构团队记忆页头和成员导航：展示成员数、共享记忆数、今日更新次数
与最近更新条目；提供唯一的顶部搜索和“问团队记忆”操作；点击问答后打开可拖动的迷你新对话
卡片，并可跳转到完整 TEAM 对话页面。

## Context and boundaries

- 统计和动态只从前端已经获得授权的 `WORKSPACE` 记忆与当前空间成员计算，不增加新 API，
  不读取成员私有记录。
- 搜索继续复用现有 `POST /search`、作者筛选和可见性边界。
- 迷你卡片不保存正文、不创建 conversation；跳转后继续使用现有 `TEAM` memory scope。
- 保持当前黑灰背景，只在按钮、头像、状态点和选中态使用低饱和蓝、绿、橙。

## Scope

- 紧凑统计页头、最近更新摘要和跨栏成员筛选。
- 顶部搜索按钮控制现有检索浮层，移除团队列表内重复搜索入口。
- 可拖动、可关闭、可跳转的团队问答迷你卡片。
- 桌面/移动响应式样式、组件回归测试和浏览器验收。

## Non-goals

- 不新增活动流、聊天或统计 API；不持久化迷你卡片位置。
- 不改变记忆可见性、搜索授权、conversation 权限或数据库。
- 不部署、提交或推送代码，除非用户另行要求。

## Acceptance criteria

- [x] 页头显示成员、共享记忆、今日更新与最近更新者。
- [x] 页面只有一个显眼的团队搜索入口，并打开现有检索浮层。
- [x] “问团队记忆”打开可拖动迷你卡片，关闭和跳转均可用。
- [x] 跳转后的新对话仍使用 TEAM memory scope。
- [x] 颜色只用于强调，不改变主背景色与权限语义。

## Rollout and recovery

纯 Web 变更，无迁移。回退团队中心、时间线受控搜索、样式和测试即可恢复。
