# InfMind-inspired subscription page

Status: completed
Owner: Codex
Last updated: 2026-08-11

## Outcome

让 Memora 套餐窗口在保留真实 Credits、升级能力和额度记录的前提下，采用用户参考图中的
大尺寸订阅面板、清晰内容层级、三档高卡片和 Pro 重点推荐视觉。

## Context and evidence

- 当前套餐窗约 920px 宽，额度总览和账本视觉权重较高，三张套餐卡较短且无推荐层级。
- 现有 OpenAPI 只提供套餐名称、周期 Credits、能力列表和内部升级接口，没有价格、月付或
  年付字段。
- 产品文档明确当前处于内测阶段；接入支付提供商前不展示虚构的扣款、续费或退款能力。
- GitNexus 对 `SubscriptionDialog` 的上游影响为 LOW，没有检测到外部调用链。

## Scope

### In scope

- 重排套餐窗口的信息架构、字体、间距、亮度、卡片层级和动效。
- Pro 套餐使用蓝色边框、推荐标签和主操作按钮形成视觉重点。
- 保留真实 Credits 使用进度、升级入口、失败提示和最近额度记录。
- 增加桌面、平板、移动端以及减少动态效果下的适配。
- 更新组件测试并做本地浏览器和完整工程验证。

### Non-goals

- 不伪造美元价格、折扣、月付或年付切换。
- 不复制 InfMind 商标、品牌资产或套餐文案。
- 不修改计费 API、套餐额度、数据库、权限或升级行为。

## Acceptance criteria

- [x] 套餐窗口接近宽屏全尺寸面板，标题和说明居中，关闭入口清晰可用。
- [x] Plus、Pro、Ultra 为三张高卡片，Pro 有清晰且不依赖 hover 的推荐标识。
- [x] 当前套餐、不可降级、可升级和请求中状态保持原有行为。
- [x] Credits 余额、使用进度、到期时间和最近额度记录仍展示真实数据。
- [x] 窄屏布局无横向溢出；减少动态效果时内容直接呈现最终状态。
- [x] 相关测试、类型检查、lint、构建和本地运行时验证通过。

## Verification

- Web 定向组件测试、类型检查和 ESLint。
- `make check` 全量检查。
- 本地 Compose 重新构建与健康检查。
- 浏览器桌面宽屏、1280×720、390×844 截图和交互验证。

## Rollout and recovery

无迁移和契约变化。回滚只需恢复本次组件、样式和测试；现有订阅与 Credits 数据不受影响。
