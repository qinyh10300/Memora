# Theme, home navigation, and compact menus

Status: completed
Owner: Codex
Last updated: 2026-08-09

## Outcome

通用设置提供可持久化的黑色与白色主题；登录用户可从侧栏 Logo 返回公开首页并保持会话；空间和账户菜单减少纵向留白。

## Scope

- 在通用设置中加入黑色、白色主题选择，并在刷新后恢复。
- 白色主题覆盖首页、登录弹窗、工作台、设置和主要功能页面。
- 登录态点击侧栏 Logo 返回首页，首页提供进入工作台入口且不要求重新登录。
- 压缩空间菜单和账户菜单的标题、分组与菜单项间距。
- 保持侧栏宽度、桌面三栏布局和移动端布局不变。

## Milestones

- [x] M1 - 实现主题状态、持久化和全局样式。
- [x] M2 - 实现登录态首页往返。
- [x] M3 - 收紧两个侧栏弹层。
- [x] M4 - 完成自动化与浏览器验证。

## Acceptance criteria

- [x] 选择白色或黑色主题后立即生效，刷新后保持。
- [x] 白色主题仍为纯黑、灰、白配色，文字和边框对比清晰。
- [x] 点击展开或收起状态的 Memora Logo 都可返回首页，登录态不丢失。
- [x] 登录态首页显示“进入工作台”，点击后恢复原工作台。
- [x] 两个展开菜单明显更紧凑，内容不裁切、可正常操作。

纯前端偏好和导航改动，无 API 或数据库迁移。移除本地主题键即可恢复默认黑色主题。
