# Public landing page and password registration

Status: Completed

Date: 2026-08-06

## Goal

为未登录访客提供一个在信息架构、首屏比例、黑蓝视觉节奏和滚动交互上参考 InfMind
官网的 Memora 品牌首页。登录用户继续直接进入现有个人 Markdown 工作台；访客可用邮箱
账号和密码注册或登录。

## Product decision

本计划覆盖此前“只使用 seed 账号、不开放公开注册”的 v0.1 限制。公开注册只创建该用户
自己的 `PERSONAL` 空间，不自动加入现有测试团队，也不改变私人记忆的可见性规则。

参考页只用于版式和交互研究。Memora 使用自己的品牌、文案、产品界面和能力说明，不复制
InfMind 的商标、宣传数据、客户背书、价格或受保护图片素材。

## Architecture boundaries

- `GET /auth/me` 成功时 `/` 直接进入现有工作台；匿名访问显示公开首页。
- 首页的“登录”打开登录表单，“快速开始”打开注册表单；成功后复用现有个人空间激活流程。
- `POST /auth/register` 原子创建用户、个人空间、OWNER 成员关系和会话。
- 邮箱全局唯一并规范化；密码使用现有 Argon2 哈希，长度为 10–128 字符。
- 注册和登录都使用现有固定窗口限流器；浏览器只接收 HttpOnly、SameSite 会话 Cookie。
- 注册用户不得自动获得测试团队、其他用户资产或私人记忆的访问权限。
- Web 与 API 继续通过生成的 OpenAPI 契约通信。

## Implementation

1. 新增注册请求/接口、共享会话建立逻辑、冲突处理、审计和身份集成测试。
2. 将匿名入口改为 Memora 品牌化长首页，包含固定导航、产品首屏、能力网格、工作流、指标、
   FAQ 和末尾 CTA；保持黑色为主、蓝色为辅。
3. 新增登录/注册响应式弹层、表单校验、模式切换、错误和忙碌状态。
4. 更新当前产品范围、认证架构和 OpenAPI 契约。
5. 运行完整检查，重新部署并验证匿名首页、注册、退出、登录和持久会话回访。

## Acceptance criteria

- 匿名首次访问看到公开首页，不在页面中直接嵌入工作台侧栏。
- 已登录会话刷新或再次访问时不经过首页，直接进入当前工作台。
- 新邮箱可注册并自动登录；刷新后会话保持，退出后回到首页，再次使用密码可登录。
- 重复邮箱、弱密码、密码确认不一致和错误凭据提供明确且不泄露敏感信息的反馈。
- 新用户只有一个个人空间，不能看到 seed 团队成员或其他用户的私有记录。
- 首页在桌面和移动端无重叠，动效尊重 `prefers-reduced-motion`。
- `make check` 通过，运行中的 API、Web 和数据库保持健康。

## Recovery

- 首页和认证弹层可独立回退，不影响已登录工作台代码和数据。
- 注册不需要数据库迁移；若停用接口，已创建用户和个人空间仍可通过登录继续使用。
- 注册事务失败时整体回滚，不留下无成员关系的用户或无所有者的个人空间。
