# 0027 Centered Chat And Docked Knowledge

Status: Active

Date: 2026-08-09

## Goal

让新对话先呈现居中的标题和输入框，首条消息发送后自然切换为底部输入的聊天布局；右侧面板默认关闭，并允许用户从助手结果中进入云知识库，或把草稿/云知识库停靠在聊天右侧。

## Product Rules

- 新对话不主动展示保存位置或右侧面板，默认可见范围仍为 `PRIVATE`。
- AI 修改只更新未保存草稿；用户仍需主动保存，团队共享仍需主动选择。
- 云知识库继续只展示当前用户有权访问的已保存记忆和文档来源。
- 右侧停靠只是界面布局能力，不改变任何 workspace 或 memory 权限。

## Recovery

本计划只调整前端状态与布局，不迁移数据库。发生回归时可逐个回退对应提交；草稿、记忆和权限数据不受影响。
